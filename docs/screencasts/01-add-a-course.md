# Screencast 01 — Add a new course

**Goal:** Show an admin how to create a course, build its sections and
lessons, attach a lesson video, and publish it so it appears in the member app.

**Length:** 3–4 minutes.

**Recording:** `01-add-a-course.mp4` (silent, ~2 min of footage; narrate over
the pauses).

**Have ready:**
- A staging/clone site login with editor access.
- The URL of one short demo video (Vimeo, YouTube, or a WordPress media URL).
- A membership in mind that should unlock the course (for the access step).

## Shot list

1. **On screen:** WordPress dashboard; point at the **Library** menu.
   **Narration:** "Everything for the member Library lives under this one
   Library menu. To make a course, we go to Library, then Courses."

2. **On screen:** Click **Library → Courses**, then **Add New Library Course**.
   **Narration:** "Add New starts a blank course."

3. **On screen:** Type a title, then a short **Excerpt**.
   **Narration:** "The title and the excerpt are what members see on the
   course card."

4. **On screen:** In **What you'll learn**, type an outcome, click **Add
   outcome**, type a second one. Tick a **Collection** in the sidebar.
   **Narration:** "A few 'what you'll learn' outcomes and a Collection help
   members find and choose the course."

5. **On screen:** Point at the **Library access** box, then click **Save
   Draft**.
   **Narration:** "This box tells us who can get in. We'll save a draft first
   so we can build the lessons."

6. **On screen:** In the **Course curriculum** box click **Open structure
   builder**. Click **Add section**, name it, click **Save structure**.
   **Narration:** "Lessons are grouped into sections, and sections live in the
   structure builder. Add a section, name it, and save the structure."

7. **On screen:** Click **Add lesson here** under the new section. Type the
   lesson title, then paste the video URL into the **Media** box.
   **Narration:** "Add lesson here opens a new lesson already placed in that
   section. Each lesson gets its video in the Media box — paste its link."

8. **On screen:** Click **Publish** on the lesson; point at **Back to course
   structure**.
   **Narration:** "Publish the lesson, and this link takes us straight back to
   the course."

9. **On screen:** Back on the course, click **Publish**; point at **Library
   access**.
   **Narration:** "Publish the course. Within about a minute it shows up in the
   app on its own — we don't touch the app."

## Call out

> Check the **Library access** box before publishing. With no MemberPress
> rule it reads "No MemberPress rule applies", which means **every** signed-in
> member can open it. Picking a Collection that an Access Group covers (e.g.
> Masterclasses) can make it protected automatically — the box will then read
> **Protected by MemberPress** and name the group. Access is covered in
> screencast 04.
