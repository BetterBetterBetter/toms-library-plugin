# Screencast 07 — Post an announcement to members

**Goal:** Show the numbered announcement boxes and, above all, checking the
audience before anything is delivered.

**Length:** about 1¼ minutes.

**Recording:** `07-post-announcement.mp4`. Shot numbers match the `r.cue(n)`
marks in the recorder spec. The recording uses **Save draft** and **Preview
audience** only — nothing is sent.

**Have ready:**
- Record on the local clone. Never deliver an announcement during recording.

## Shot list

1. **On screen:** **Library → Announcements**, **Add New**.
   **Narration:** "Announcements to members start under Library,
   Announcements. Add New starts one."

2. **On screen:** Title, then box **1. Message**.
   **Narration:** "The boxes are numbered, so just work down them. One is the
   message itself."

3. **On screen:** Box **2. Destination**; pick the demo course.
   **Narration:** "Two is where it sends members. Here, the new course."

4. **On screen:** Box **3. Audience**; choose an active membership.
   **Narration:** "Three is who gets it. Here, members with an active
   membership. Choose carefully."

5. **On screen:** Box **4. Delivery**, then **Save draft**.
   **Narration:** "Four is delivery. For now, save a draft. Your destination
   and audience are kept, and nothing is sent."

6. **On screen:** Box **5. Review**; **Preview audience**.
   **Narration:** "Five is the review. Preview the audience to see who would
   receive it, before anything goes out."

7. **On screen:** Point at **4. Delivery** again — do not send.
   **Narration:** "Sending isn't switched on yet, so announcements stay as
   drafts. When it is, only deliver once the audience looks right."

## Call out

> Sending is not switched on yet: announcements save as drafts only. Once it
> is, delivery reaches real members, so always preview the audience first.
