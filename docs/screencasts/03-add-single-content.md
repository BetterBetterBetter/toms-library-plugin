# Screencast 03 — Add a single video or resource

**Goal:** Show how to add a standalone piece of content (a one-off video with a
download) that isn't part of a course or series.

**Length:** about 1 minute.

**Recording:** `03-add-single-content.mp4`. Shot numbers match the `r.cue(n)`
marks in the recorder spec.

**Have ready:**
- A demo video link and a download URL (worksheet, slides).

## Shot list

1. **On screen:** **Library → Content**, then **Add New**.
   **Narration:** "For a one-off, like a single talk that isn't part of a
   course, go to Library, then Content, and add a new item."

2. **On screen:** Type the title; paste the video link into the **Media** box.
   **Narration:** "Give it a title, then paste the video link into the Media
   box."

3. **On screen:** In **Library resources**, add a label and a link.
   **Narration:** "Downloads, like a worksheet or slides, go in Library
   resources. Add a label and the link."

4. **On screen:** The **Library placement** box, showing **Standalone
   content**.
   **Narration:** "Library placement says where it lives. Standalone content
   means it stands on its own, outside any course or series."

5. **On screen:** The **Library access** box, then click **Publish**.
   **Narration:** "Check the access box to see who can open it, then
   publish."

## Call out

> Standalone content is authorised on itself — if it's paid, it needs to be
> in an Access Group (screencast 04).
