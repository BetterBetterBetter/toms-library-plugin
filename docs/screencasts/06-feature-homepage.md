# Screencast 06 — Feature content on the Library homepage

**Goal:** Show how to choose what members see first on the Library homepage.

**Length:** about 30–40 seconds.

**Recording:** `06-feature-homepage.mp4`. Shot numbers match the `r.cue(n)`
marks in the recorder spec. The recorder restores the homepage arrangement
afterwards.

**Have ready:**
- A few published items to arrange.

## Shot list

1. **On screen:** **Library → Homepage**.
   **Narration:** "The Homepage screen sets what members see first when they
   open the Library."

2. **On screen:** Search for the item; set its row to **Featured**.
   **Narration:** "Find an item, then choose the row it belongs in. Here,
   Featured."

3. **On screen:** Click **Move up** on the item.
   **Narration:** "The arrows set its order within the row."

4. **On screen:** Click **Save homepage**.
   **Narration:** "Save homepage, and the app follows. Featuring changes
   where something appears, not who can open it."

## Call out

> Featuring something doesn't change who can access it — it only changes where
> it appears. Access still comes from its Access Group.
