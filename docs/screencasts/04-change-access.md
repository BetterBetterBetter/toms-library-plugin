# Screencast 04 — Change who can access something

**Goal:** Teach the most important, most-often-fumbled task: access is not set
on the course. It comes from **Access Groups** — packages of Library content
assigned to MemberPress memberships — and only changes for members when the
draft is **published**.

**Length:** about 1½ minutes.

**Recording:** `04-change-access.mp4`. Shot numbers match the `r.cue(n)`
marks in the recorder spec. The recording ticks the demo course in a group but
**never saves or publishes** Access Groups; it only points at those buttons.

**Have ready:**
- A demo course that is currently open (no rule).
- An already-protected course to show the end state.

## Shot list

1. **On screen:** The demo course's **Library access** box.
   **Narration:** "Here's the part people get wrong most often. You don't set
   access on the course itself. This Library access box is a mirror. It
   reports what MemberPress decides."

2. **On screen:** **Library → Access Groups**; point at the **Live** panel,
   then the **Draft** panel.
   **Narration:** "Access is managed under Library, Access Groups. Live is
   what members have now. Draft is where your changes wait until you
   publish."

3. **On screen:** Open a group; under **What this group unlocks**, tick the
   demo course.
   **Narration:** "An Access Group is a package of content. Open a group, and
   under What this group unlocks, tick the course."

4. **On screen:** Point at the group's memberships, then **Save draft**.
   **Narration:** "Each group lists the memberships that include it. Save
   draft keeps your change. Saving never changes member access."

5. **On screen:** A MemberPress membership's **Library Access Groups** box.
   **Narration:** "You can also tick groups from a MemberPress membership, in
   its Library Access Groups box. That saves to the draft as well."

6. **On screen:** Back on Access Groups; point at **Preview the check
   first**, then **Publish** (not clicked).
   **Narration:** "When you're ready, preview the check first. Publishing
   checks every current member. If anyone would lose access, nothing is
   published, and you see exactly who."

7. **On screen:** A protected course; its **Library access** box reads
   **Protected by MemberPress** and names the group.
   **Narration:** "Once it's live, the course's access box reads Protected by
   MemberPress and names the group. That's how you know it worked."

## Call out

> "No MemberPress rule applies" = open to every signed-in member. For paid
> content that is almost always wrong. Saving an Access Group only changes the
> draft; members are affected only after **Publish**. Afterwards, confirm the
> access box reads **Protected by MemberPress**.
