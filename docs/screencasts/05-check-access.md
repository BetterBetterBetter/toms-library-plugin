# Screencast 05 — Check who can access something

**Goal:** Show the three ways to confirm what's locked, what's open, and which
group unlocks a given item.

**Length:** about 45 seconds.

**Recording:** `05-check-access.mp4`. Shot numbers match the `r.cue(n)`
marks in the recorder spec.

**Have ready:**
- One protected course and one open course, so the contrast is visible.

## Shot list

1. **On screen:** A protected course's **Library access** box.
   **Narration:** "The fastest check is on the item itself. This course is
   protected by MemberPress, and the box names what unlocks it."

2. **On screen:** The demo course's **Library access** box.
   **Narration:** "Compare an open one. When no rule applies, every signed-in
   member can open it."

3. **On screen:** **Library → Settings**, **Access** tab; scroll.
   **Narration:** "For the whole catalogue at once, the Access overview lives
   under Library, Settings."

4. **On screen:** **Library → Courses**; point at the access column.
   **Narration:** "And every Library list shows access at a glance, without
   opening anything."

## Call out

> If an item shows as open that you expected to be paid, go to screencast 04
> and add it to an Access Group.
